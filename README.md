# Current-Starved-Ring-VCO-in-ASAP7-7nm
Build a working current-starved ring VCO in a 7nm FinFET PDK at 0.7 V, where the 4-device stack leaves little headroom. Characterise it: tuning, power, supply sensitivity, phase noise and PVT.Find what actually limits phase noise, since the paper gives only a transistor-count explanation.Improve the design using that finding and quantify the cost.
